## 四、复现步骤（老师/助教验收用）

```powershell
# 1. 启动全部服务（首次需 build，约 5 分钟）
cd D:\xiangmushixun-bde
Copy-Item .env.example .env      # 然后填入 SUPERSET_SECRET_KEY 与 LLM_API_KEY
docker compose build
docker compose up -d
docker compose ps                # 期望 6 个 healthy + 2 个 Exited(0)

# 2. 初始化可视化数据（约 2 分钟）
cd 第4周\py
python sql_runner.py ..\sql\ads\create_ads_w4.sql
python sql_runner.py ..\sql\ads\load_ads_w4.sql
python sql_runner.py ..\sql\ads\verify_ads_w4.sql
python export_to_clickhouse.py
python export_to_mysql.py

# 3. 打开三个界面
start http://localhost:8088     # Superset（admin/admin）
start http://localhost:8000     # ECharts 大屏
start http://localhost:8501     # Streamlit 问答
```

或直接双击 `第4周/一键运行/` 里的 bat（0 自检 → 1 初始化 → 2 部署 → 3/4/5 打开界面）。

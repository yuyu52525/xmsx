# 如何运行本程序

> 面向：需要在别人的电脑上跑这套代码，或答辩时现场演示
> 更新日期：2026-11-10

---

## 一、先说结论：`.py` 不要双击

双击 `.py` 会**闪一下就关**，原因有三个：

| 原因 | 后果 |
|---|---|
| 系统里 `.py` 关联的是 **Python 3.8.5**，而本项目要 3.10+ | 语法报错（`str \| None` 这种写法 3.8 不支持） |
| 3.8 环境里**一个依赖都没装**（pandas/sklearn/openai 全缺） | `ModuleNotFoundError` |
| 出错后窗口立即关闭 | 你连报错都看不见 |

所以本项目提供了**双击就能跑的启动器**。

## 二、推荐方式：双击 `一键运行/` 里的 bat

目录：`第3周\一键运行\`

| 文件 | 作用 | 消耗 token |
|---|---|---|
| `0_环境自检.bat` | 检查 Python 版本、10 个依赖、`.env`、Hive 连接 | 0 |
| `1_大模型连通性自检.bat` | 验证 API Key 是否可用 | ≈13 |
| `2_NL2SQL问答.bat` | 输入中文问题 → 自动生成 SQL → 查 Hive → 出结果 | ≈3,000/次 |
| `3_生成AI洞察.bat` | 异常检测 + 归因 + 模型写摘要 | ≈4,000 |
| `4_重跑预测模型.bat` | 重新训练、回测、出 4 张图（1~2 分钟） | 0 |
| `5_导出KPI表格.bat` | 重新生成 `KPI指标结果表.xlsx` | 0 |
| `6_查看token用量.bat` | 看累计调用次数与 token 数 | 0 |

**第一次用，先双击 `0_环境自检.bat`**，看到"结论：环境就绪"再往下走。

### 启动器做了什么

```bat
chcp 65001                              :: 切 UTF-8，否则中文全是问号
set PYTHONIOENCODING=utf-8
cd /d "%~dp0..\py"                      :: 切到 py 目录（脚本靠相对路径找 .env）
:: 依次尝试：DSH 内置 Python → py -3.12 → py -3.11 → py -3.10 → python
:: 找到能 import pandas 的那个就用它
%PYEXE% run.py <子命令>
pause                                   :: 跑完停住，方便看输出
```

**为什么中间要拐一层 `run.py`**：最初把中文提示直接写在 bat 里，cmd 的代码页把 `if (...)` 块里的中文解析坏了，报 `'y"' 不是内部或外部命令`。改成"bat 只找 Python、逻辑全在 Python 里"之后就稳了。

## 三、备选方式

### 方式三：VS Code

1. 用 VS Code 打开 `第3周` 文件夹
2. `Ctrl+Shift+P` → `Python: Select Interpreter` → 选 **3.12.14**（路径含 `dsh-runtimes`）
3. 打开任意 `.py`，按 `F5` 或右上角运行按钮

### 方式四：cmd 命令行

```cmd
cd /d D:\xiangmushixun-bde\第3周\py
python run.py check
python run.py nl2sql
```

`run.py` 是统一入口，子命令：`check` / `llm` / `nl2sql` / `insight` / `forecast` / `kpi` / `usage`。

## 四、跑之前必须满足的两个前提

### 1. Hive 要启动

```powershell
cd D:\xiangmushixun-bde
docker compose up -d
docker ps        # 三个容器都应是 Up：mysql / hive-metastore / hive-server
```

没启动的话，所有查数脚本都会报 `Could not connect to any of [('::1', 10000, 0, 0)]`。

### 2. `.env` 要存在

`第3周\py\.env`（已在 `.gitignore` 中，不会进 Git）。内容形如：

```ini
LLM_API_KEY=你的Key
LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4
LLM_MODEL=glm-4-flash-250414
```

只有 `--llm` / NL2SQL 这类要调模型的才需要 Key；`4_重跑预测模型.bat` 和 `5_导出KPI表格.bat` 是纯本地计算，没有 Key 也能跑。

## 五、常见报错

| 现象 | 原因 | 解决 |
|---|---|---|
| 窗口闪一下就关 | 双击的是 `.py` 不是 `.bat` | 用 `一键运行/` 里的 bat |
| `[ERROR] No usable Python found` | 没装 3.10+，或没装依赖 | 装 Python 3.12 后 `pip install -r` 那串依赖 |
| 中文全是问号 | 代码页不对 | 用 bat 启动（已内置 `chcp 65001`） |
| `Could not connect to any of [('::1', 10000, 0, 0)]` | Hive 没起 | `docker compose up -d` |
| `[结论] 未配置 Key` | `.env` 不存在或变量名写错 | 复制 `.env.example` 为 `.env` |
| `401` | Key 错/带空格/过期 | 重新复制，注意首尾无空格 |
| `404` | 模型名不对 | 用 `glm-4-flash-250414` |
| `429` | 限流或额度耗尽 | 等一分钟；或换模型 |

## 六、token 到底消耗多少

**"免费"指的是不扣钱，不是不消耗 token。** 每次调用都会真实消耗输入/输出 token，也会占用你的额度与并发限制。

实测数据（用当前这套 schema）：

| 动作 | 输入 | 输出 | 合计 |
|---|---|---|---|
| 连通性自检 | ~10 | ~3 | ≈13 |
| 一次 NL2SQL | **2,804** | 57 | **≈2,861** |
| 一次 AI 洞察摘要 | ~3,500 | ~150 | ≈3,650 |

**输入为什么这么大**：NL2SQL 要把 13 张表、151 个字段的结构全塞进 Prompt，这部分就占了两千多 token。如果以后表更多，要么精简 schema（只给相关表），要么改用"先检索表、再给结构"的两段式。

想看自己的累计用量：

```powershell
python llm_client.py --usage
```

每次调用都会往 `第3周/evidence/llm_usage.log` 追加一行（本地文件，已 gitignore）。

> 注意：本地记录**不等于服务商账单**。服务商按自己的口径计费，可能包含系统提示等隐藏开销。要精确对账，去控制台的用量页面看。

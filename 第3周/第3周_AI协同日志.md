## 四、问题与解决

**遇到的问题（按影响排序）**

1. **Tez 计数器超限**：9 路 `union all` 校验报 `Too many counters: 121 max=120`，整个 `load_dws.sql` 退出码 2。逐一试过 `set tez.counters.max` / `set tez.counters.limit`，均无效。
2. **周键跨年错乱**：`2024-W01` 的 `week_start/week_end` 变成 1/1~12/31，等于 53 周里有 1 周吞掉了全年。
3. **训练集天数对不上**：报告 322 天 vs 脚本 307 天。
4. **异常归因结论空泛**：只做渠道拆解，等于说"哪儿都降了"。
5. **无 API Key**：NL2SQL 的模型生成环节无法端到端验证。
6. **容器崩溃循环**：`hive-server` 反复 Restarting，`show databases` 只剩 `default`，一度以为元数据丢了。
7. **CRLF 导致文本替换失败**：同一个脚本两次运行结果不同。

**AI 是否有效解决**

6/7 由 AI 定位并解决，1 个（无 Key）无法解决、已改为降级方案并如实标注。

**最终如何解决**

| 问题 | 解决方式 |
|---|---|
| 1 | 拆成"一条语句一张表"；结论：该 Tez 版本的 120 上限在 AM 侧固定，参数改不动 |
| 2 | 弃用 `dim_date.week_of_year`，自建 `tmp_date_week` 推导 |
| 3 | `dropna()` → `dropna(subset=FEATURES)` |
| 4 | 加 `GMV = 订单量 × 客单价` 拆解，区分量跌/价跌 |
| 5 | 加 `--demo` 模式跑通链路，输出中明示"非模型输出"；真实调用待配 Key |
| 6 | 查 MySQL `metastore.DBS` 确认 4 库 52 表都在，判定是容器 pid 残留 → `--force-recreate` 重建，数据无损 |
| 7 | 匹配串改 `\r\n`；记录为跨平台协作的注意事项 |

## 五、反思与总结

**AI 协同带来的价值**

最大价值不是"写得快"，而是**"它敢写我懒得写的东西"**——9 张表的 DDL、9 张表的 ETL、6 个 Python 脚本，手写要两三天，AI 半小时出初稿。省下的时间被我用来做真正需要判断的事：核对口径、设计对照实验、想清楚结论的边界。

第二价值是**排错**。Tez 计数器、pyhive 的 SASL 认证、CRLF 匹配失败，这些都不是"想"得出来的，得靠快速试错。AI 能一分钟内给出 5 个可能原因并逐个验证，比我翻文档快得多。

**AI 的局限与风险**

本周最值得记的一条：**AI 会先给结论，再找理由。**

`ai_insight.py` 的初版摘要写"波动主要来自单日订单量的随机起伏"——但当时脚本根本没算订单量指数，这个结论是"蒙"的。它恰好对了（确实是量跌），但**推理过程是空的**。如果那天蒙错了，我会带着一个错误的结论去答辩，而且它读起来毫无破绽。

这类错误比"报错"危险得多：报错会逼你修，而"听起来对的错话"会一路通关到最终交付。

第二个风险是**因果越界**。问它"为什么 10 月 8 日客单价低"，它会编出"促销活动"——但数据里根本没有促销字段。它的默认行为是**补一个合理的解释**，而不是说"数据不支持"。

第三个风险是**默认你的输入是对的**。复购率 100%、漏斗购买率高于加购率，它第一反应是"解释这个现象"，而不是"质疑这个指标"。这次是我在写校验时主动要求它做"指标体检"，才发现这四个坑。

**本次协作中我的能力提升**

1. 学会了**给 AI 设边界**：不是"帮我写个分析"，而是"必须加基线对照""必须报 MBE""只能陈述数据支持的事实"；
2. 学会了**不信第一次输出**：本周 8 条记录里 4 条是推翻重做，比例 50%；
3. 对 Hive/Tez 的脾气更熟了（计数器上限、分区列位置、中文别名、动态分区）；
4. 理解了"模型没跑赢基线"这种负面结论**也是有价值的交付物**——它比一个漂亮但站不住的 MAPE 更值得写进报告。

**对 AI 协同的改进建议**

1. **结论必须能指回字段**：报告里每出现一次"因为/由于/导致"，都要能说出是哪个字段支撑的，说不出来就删掉；
2. **先要对照，再要结论**：任何模型效果都要有朴素基线，否则不知道它到底有没有用；
3. **让 AI 自证**：要求它给出"这个结论可能错在哪"，比要求它"给个结论"有用；
4. **数字人工复核**：AI 写的摘要里的数字，必须逐个回表核对，尤其是它从多处拼接的数字。
